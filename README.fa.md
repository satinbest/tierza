## 🇮🇷 درباره تیرزا

**تیرزا (Tierza)** یک افزونه متن‌باز، ماژولار و بومی قیمت‌گذاری B2B، عمده‌فروشی و سطوح قیمتی همکار برای ووکامرس است که بهطور خاص بر اساس نیازها، ساختار مالی و الگوهای کسب‌وکارهای ایرانی طراحی شده است.

این افزونه با پایبندی به اصول **Clean Architecture** توسعه می‌یابد تا هیچ‌گونه تداخلی با داده‌های اصلی محصولات یا سازوکارهای استاندارد پرداخت و تسویه‌حساب ووکامرس ایجاد نکند.

### قابلیت‌های پیاده‌سازی‌شده (Completed):
- [x] **راه‌اندازی و معماری تمیز (TRZ-001)**: ساختار لایه‌بندی‌شده (Domain, Application, Infrastructure, Integration, Rest, Admin)، بارگذاری امن PSR-4، و پایداری در صورت غیرفعال بودن ووکامرس.

- [x] **محیط توسعه و آزمون زنده (TRZ-002)**: پشته کامل داکر با `@wordpress/env` (وردپرس 6.5.5، ووکامرس 8.5.2، MariaDB)، استانداردهای کدهای وردپرس (PHPCS)، تحلیل عمیق PHPStan سطح ۸، و تست‌های مرورگر Playwright.
- [x] **خط لوله یکپارچه‌سازی مداوم (TRZ-003)**: اعتبارسنجی خودکار GitHub Actions برای آزمون‌های ماتریسی PHP 8.1 و 8.4، کیفیت JS/TS، تست زنده کانتینری و بسته‌بندی ZIP مستقل.
- [x] **طرحواره پایگاه داده و لایه پایداری داده (TRZ-004)**: ایجاد جداول استاندارد وردپرس (`tierza_groups`، `tierza_rules`، `tierza_user_groups`)، یکتایی اتمیک قوانین فعال در سطح پایگاه داده (`uq_active_rule`)، اعتبارسنجی ارجاع موجودیت‌ها، مهاجرت‌های ایمن و تکرارپذیر، بازسازی داده‌های قدیمی (Backfill) بدون حذف داده، و ۳۱ آزمون یکپارچگی زنده دیتابیس با داکر.
- [x] **قراردادها و رابط‌های دامنه قیمت‌گذاری (TRZ-005)**: تعریف ساختار غیرقابل‌تغییر PricingContext، شیء ارزش پولی با دقت محاسباتی رشته‌ای قطعی (Money و DecimalMath بدون خطای ممیز شناور و با پیاده‌سازی پشتیبان Pure-PHP)، سلسله‌مراتب تقدم ۹ گانه قوانین (RuleResolverInterface)، قرارداد محاسبات (PriceCalculatorInterface)، شیء PricingResult با کدهای ماشین‌خوان و ۲۰۹ تست واحد PHPUnit با ۸۱۰ Assertion.
- [x] **موتور حل تعارض و تقدم قطعی قوانین (TRZ-006: Deterministic Rule Resolver)**: موتور انتخاب قطعی قانون برنده طبق اولویت ۹ گانه PRD، بهینه‌سازی واکشی تک‌کوئری پایگاه داده (`find_active_for_targets()`)، تضمین صفر کوئری برای مهمانان، سیاست ۳ مرحله‌ای حل تعارض سلسله‌مراتب دسته‌بندی، توارث قوانین محصول والد برای متغیرها، پشتیبانی از تخفیف صریح ۰٪ و قیمت صفر، گاردها و استثناهای ساختاریافته، ۵۳ تست واحد و ۴ تست یکپارچگی زنده دیتابیس (مجموعاً ۲۸۸ تست واحد با ۱۲۱۵ Assertion و ۳۷ تست زنده MariaDB).
- [x] **موتور محاسبه قطعی و رسمی قیمت (TRZ-007: Authoritative Price Calculator)**: پیاده‌سازی محاسبات دقیق تخفیف درصدی و قیمت مقطوع محصول/متغیر با رشته‌های اعشاری، پشتیبانی کامل از تخفیف صریح ۰٪، تخفیف ۱۰۰٪، قیمت صفر و اضافه‌بها، گردکردن نیمه‌به‌بالا (Half-Up) در مرز خروجی ارز (۰ تا ۶ رقم اعشار)، آگاهی از قیمت حراجی فعال ووکامرس، اعتبارسنجی شکست‌ناپذیر اینورینت‌ها با `PricingCalculationException`، ۳۹ تست اختصاصی، و آزمون یکپارچگی زنده جریان داده از قوانین پایگاه داده تا نتیجه نهایی.
- [x] **آزمون‌های جامع قیمت‌گذاری و مقاوم‌سازی قابلیت اطمینان (TRZ-008: Comprehensive Pricing Tests & Reliability Hardening)**: ماتریس جدول‌محور ۸ سطح تقدم و Fallback، ایزولاسیون کامل مشتری و گروه، توارث متغیرها و حل تعارض ۳ مرحله‌ای دسته‌بندی‌ها، اعتبارسنجی بردارهای مالی با اوراکل مستقل محاسباتی گویا (`ExactRationalPricingOracle`)، آزمون‌های مبتنی بر ویژگی و دگرریختی (Property-Based) با بذر بازتولیدپذیر، مهار سقف ظرفیت ذخیره‌سازی `DECIMAL(20,6)` (۱۴ رقم صحیح) و رد نماد علمی و برش خاموش، آزمون تزریق خطا، آزمون یکپارچگی زنده دیتابیس با تغییرناپذیری داده‌های کالا و سفارش‌ها، و اندازه‌گیری مبنای کارایی (۴۵۹ تست واحد PHPUnit با ۳۰۰۷ Assertion و ۴۰ تست زنده MariaDB با ۲۶۹ Assertion).
- [x] **سیستم کشینگ و واکشی دسته‌ای کوئری‌ها (TRZ-009: Pricing Cache & Batch Prefetching)**: معماری کش چندلایه‌ای در محدوده درخواست (`PricingCacheInterface`، `RequestPricingCache`، `PricingCacheKeyGenerator`، `PricingBatchPrefetcher`، `CachedRuleRepository`)، واسط واکشی دسته‌ای `resolve_batch` با پیش‌واکشی قوانین نامزد در یک کوئری تک‌ایندکس، کاهش چشمگیر کوئری‌های پایگاه داده (کاهش ۹۹٪ برای ۱۰۰ محصول از ۱۰۰ کوئری به ۱ کوئری در ۳.۹۹ میلی‌ثانیه؛ کاهش ۹۹.۸٪ برای ۵۰۰ محصول از ۵۰۰ کوئری به ۱ کوئری در ۳.۵۲ میلی‌ثانیه؛ و ۱۰۰٪ اصابت کش در کوئری‌های تکراری)، ایزولاسیون کامل کاربران، مرزبندی دقیق نامعتبرسازی مشتریان (`cust:auth:<id>#`) برای جلوگیری از همپوشانی زیررشته‌ها، سقف محدود وضعیت گروه‌ها (پیش‌فرض ۵۰۰ ورودی با تخلیه FIFO و استعلام مجدد در صورت خروج)، واکشی دسته‌ای ناهمگن در یک کوئری SQL، نامعتبرسازی خودکار در رویدادهای ذخیره/حذف، و مهار ظرفیت حافظه با الگوریتم FIFO (۵۰۸ تست واحد PHPUnit با ۵۳۸۴ Assertion و ۴۶ تست زنده MariaDB با ۶۰۵ Assertion).
- [x] **یکپارچه‌سازی قیمت‌گذاری محصولات ووکامرس (TRZ-010: WooCommerce Product Pricing Integration)**: لایه یکپارچگی رسمی ووکامرس (`ProductPricingAdapter` و `ProductPricingIntegration`)، فیلترهای استاندارد قیمت (`woocommerce_product_get_price`، `woocommerce_product_variation_get_price`، `woocommerce_variation_prices_price`، `woocommerce_get_price_html`)، دریافت امن قیمت بدون فیلتر با `$product->get_price('edit')`، قفل‌های ضدبازگشت و بازورود (Reentrancy Guard)، عدم دستکاری مقادیر اصلی پایگاه داده (`_price`، `_regular_price`، `_sale_price`)، آگاهی از حراج‌های زمان‌بندی‌شده، استخراج هویت مشتری از سشن رسمی ورود (`get_current_user_id()`)، ایزولاسیون کش ترنزینت بازه‌های متغیرها با `woocommerce_get_variation_prices_hash`، واکشی دسته‌ای حلقه‌های آرشیو به همراه کش ترم‌های دسته‌بندی (۰ کوئری در حلقه)، گاردهای محافظتی صفحات مدیریت و ایمپورت/اکسپورت CSV، آزمون‌های E2E مرورگر Playwright روی فروشگاه، ۵۲۹ تست PHPUnit با ۵۴۵۹ Assertion و ۵۲ تست زنده MariaDB با ۶۵۴ Assertion.

## 🚀 راهنمای نصب

### روش اول: نصب از طریق فایل فشرده (ZIP)
1. آخرین فایل آماده‌شده `dist/tierza.zip` را دانلود کنید.
2. در پیشخوان وردپرس به بخش **افزونه‌ها > افزودن افزونه > بارگذاری افزونه** بروید.
3. فایل ZIP را انتخاب کرده و بر روی **نصب** و سپس **فعال‌سازی** کلیک نمایید.

### روش دوم: راه‌اندازی برای توسعه‌دهندگان
```bash
# کلون کردن مخزن
git clone https://github.com/satinbest/tierza.git
cd tierza

# نصب وابستگی‌های PHP
composer install

# نصب وابستگی‌های جاوااسکریپت و ابزارها
npm install

# کامپایل فایل‌های باینری ترجمه
php bin/compile-mo.php

# ساخت است‌های فرانت‌اند
npm run build

# اجرای محیط تست زنده وردپرس (نیازمند Docker)
npm run env:start
```

## 🧪 دستورات تست و کنترل کیفیت

| دستور | توضیحات |
| :--- | :--- |
| `composer test` | اجرای تمامی تست‌های PHPUnit (واحد و یکپارچه‌سازی) |
| `composer phpstan` | تحلیل ایستای کدهای PHP در سطح Level 8 |
| `composer phpcs` | اعتبارسنجی کدهای PHP بر اساس استانداردهای رسمی وردپرس |
| `npm run type-check` | بررسی سلامت تایپ‌های TypeScript |
| `npm run lint:js` | اعتبارسنجی کدهای جاوااسکریپت با ESLint |
| `npm run test:e2e` | اجرای ۴ آزمون مرورگر Playwright روی محیط لایو کانتینری |
| `composer build:zip` | ساخت بسته نصبی ایزوله و مستقل `dist/tierza.zip` |
