## 🇮🇷 درباره تیرزا

**تیرزا (Tierza)** یک افزونه متن‌باز، ماژولار و بومی قیمت‌گذاری B2B، عمده‌فروشی و سطوح قیمتی همکار برای ووکامرس است که بهطور خاص بر اساس نیازها، ساختار مالی و الگوهای کسب‌وکارهای ایرانی طراحی شده است.

این افزونه با پایبندی به اصول **Clean Architecture** توسعه می‌یابد تا هیچ‌گونه تداخلی با داده‌های اصلی محصولات یا سازوکارهای استاندارد پرداخت و تسویه‌حساب ووکامرس ایجاد نکند.

## 🚦 وضعیت فعلی توسعه (Development Status)

> [!IMPORTANT]
> این پروژه در حال حاضر در نسخه **`0.1.0-dev`** قرار دارد.  
> هسته زیرساختی، سازگاری محیطی، ابزارهای توسعه و خط لوله CI تکمیل شده است. **موتور محاسبه قیمت و جداول پایگاه داده در گام‌های بعدی پیاده‌سازی می‌شوند.**

### قابلیت‌های پیاده‌سازی‌شده (Completed):
- [x] **راه‌اندازی و معماری تمیز (TRZ-001)**: ساختار لایه‌بندی‌شده (Domain, Application, Infrastructure, Integration, Rest, Admin)، بارگذاری امن PSR-4، و پایداری در صورت غیرفعال بودن ووکامرس.
- [x] **بومی‌سازی و چندزبانه بودن**: پشتیبانی کامل از چینش راست‌به‌چپ (RTL)، فایل‌های ترجمه کامپایل‌شده فارسی (`fa_IR.mo`)، و متن‌های پشتیبان انگلیسی (Fallback).
- [x] **محیط توسعه و آزمون زنده (TRZ-002)**: پشته کامل داکر با `@wordpress/env` (وردپرس 6.5.5، ووکامرس 8.5.2، MariaDB)، استانداردهای کدهای وردپرس (PHPCS)، تحلیل عمیق PHPStan سطح ۸، و تست‌های مرورگر Playwright.
- [x] **خط لوله یکپارچه‌سازی مداوم (TRZ-003)**: اعتبارسنجی خودکار GitHub Actions برای آزمون‌های ماتریسی PHP 8.1 و 8.4، کیفیت JS/TS، تست زنده کانتینری و بسته‌بندی ZIP مستقل.
- [x] **طرحواره پایگاه داده و لایه پایداری داده (TRZ-004)**: ایجاد جداول استاندارد وردپرس (`tierza_groups`، `tierza_rules`، `tierza_user_groups`)، یکتایی اتمیک قوانین فعال در سطح پایگاه داده (`uq_active_rule`)، اعتبارسنجی ارجاع موجودیت‌ها، مهاجرت‌های ایمن و تکرارپذیر، بازسازی داده‌های قدیمی (Backfill) بدون حذف داده، و ۳۱ آزمون یکپارچگی زنده دیتابیس با داکر.
- [x] **قراردادها و رابط‌های دامنه قیمت‌گذاری (TRZ-005)**: تعریف ساختار غیرقابل‌تغییر PricingContext، شیء ارزش پولی با دقت محاسباتی رشته‌ای قطعی (Money و DecimalMath بدون خطای ممیز شناور و با پیاده‌سازی پشتیبان Pure-PHP)، سلسله‌مراتب تقدم ۹ گانه قوانین (RuleResolverInterface)، قرارداد محاسبات (PriceCalculatorInterface)، شیء PricingResult با کدهای ماشین‌خوان و ۱۳۶ تست واحد PHPUnit.

## 🚀 راهنمای نصب

### روش اول: نصب از طریق فایل فشرده (ZIP)
1. آخرین فایل آماده‌شده `dist/tierza.zip` را دانلود کنید.
2. در پیشخوان وردپرس به بخش **افزونه‌ها > افزودن افزونه > بارگذاری افزونه** بروید.
3. فایل ZIP را انتخاب کرده و بر روی **نصب** و سپس **فعال‌سازی** کلیک نمایید.

### روش دوم: راه‌اندازی برای توسعه‌دهندگان
```bash
# کلون کردن مخزن
git clone https://github.com/satinbest/tierza.git
cd tierza

# نصب وابستگی‌های PHP
composer install

# نصب وابستگی‌های جاوااسکریپت و ابزارها
npm install

# کامپایل فایل‌های باینری ترجمه
php bin/compile-mo.php

# ساخت است‌های فرانت‌اند
npm run build

# اجرای محیط تست زنده وردپرس (نیازمند Docker)
npm run env:start
```

## 🧪 دستورات تست و کنترل کیفیت

| دستور | توضیحات |
| :--- | :--- |
| `composer test` | اجرای تمامی تست‌های PHPUnit (واحد و یکپارچه‌سازی) |
| `composer phpstan` | تحلیل ایستای کدهای PHP در سطح Level 8 |
| `composer phpcs` | اعتبارسنجی کدهای PHP بر اساس استانداردهای رسمی وردپرس |
| `npm run type-check` | بررسی سلامت تایپ‌های TypeScript |
| `npm run lint:js` | اعتبارسنجی کدهای جاوااسکریپت با ESLint |
| `npm run test:e2e` | اجرای ۴ آزمون مرورگر Playwright روی محیط لایو کانتینری |
| `composer build:zip` | ساخت بسته نصبی ایزوله و مستقل `dist/tierza.zip` |
