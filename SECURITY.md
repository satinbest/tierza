# Security Policy

The Tierza development team takes the security of our software and users seriously.

---

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.1.0-dev` | :white_check_mark: |
| `< 0.1.0` | :x: |

---

## Reporting a Vulnerability

If you discover a security vulnerability in Tierza:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately via **GitHub Security Advisories** on the official repository (`https://github.com/satinbest/tierza/security/advisories/new`).
3. Alternatively, email the core security team at `security@tierza.org`.

### What to Include in Your Report
- Detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept (PoC).
- Potential impact on WooCommerce store data, customer pricing, or unauthorized access.

### Response Timeline
- We will acknowledge receipt of your report within 48 hours.
- We will provide regular status updates until a patch is developed and verified.
- Once a fix is verified, a patched release and public advisory will be issued.
