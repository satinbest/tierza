سیستم جامع و بومی قیمت‌گذاری همکار، عمده‌فروشی و B2B برای فروشگاه‌های ووکامرس ایران.

== Description ==

تیرزا (Tierza) افزونه‌ای متن‌باز و قدرتمند برای مدیریت قیمت‌های همکار، عمده و سازمانی در ووکامرس است که با در نظر گرفتن نیازهای بومی کسب‌وکارهای ایرانی طراحی شده است.

= ویژگی‌ها =
* تعریف نامحدود گروه‌های مشتریان B2B.
* اعمال تخفیف‌های درصدی و قیمت‌های مقطوع.
* اولویت‌بندی شفاف و تضمین‌شده قوانین بدون اثر مخرب روی قیمت‌های اصلی محصولات.
* سازگاری کامل با زبان فارسی و محیط کاربری راست‌به‌چپ (RTL).
* محاسبات دقیق و مطمئن در سبد خرید و تسویه‌حساب.

== Installation ==

1. فایل `tierza.zip` را از بخش افزونه‌ها > افزودن افزونه بارگذاری کنید.
2. افزونه را فعال نمایید.
3. از منوی مدیریت «تیرزا» در پیشخوان وردپرس به تنظیمات و وضعیت دسترسی خواهید داشت.

== Frequently Asked Questions ==

= آیا تیرزا به لایسنس یا ionCube نیاز دارد؟ =
خیر، تیرزا ۱۰۰٪ متن‌باز و با مجوز GPL-2.0-or-later منتشر شده است و به هیچ ابزار کدگذاری شده یا سرویس ابری نیازی ندارد.

= آیا قیمت‌های اصلی محصول دستکاری می‌شوند؟ =
خیر، تیرزا هرگز مقادیر regular_price یا sale_price اصلی محصولات را بازنویسی نمی‌کند و محاسبات پویا از طریق فیلترهای ووکامرس انجام می‌شود.
