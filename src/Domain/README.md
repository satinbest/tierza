# Tierza — Domain Layer

This directory contains pure business entities, value objects, and repository interfaces.
The domain layer has zero dependency on WordPress, WooCommerce, or external infrastructure.

## Subdirectories (Planned)
- `Model/` — Domain entities (e.g. `CustomerGroup`, `PricingRule`, `PriceResolution`)
- `Repository/` — Repository interfaces
- `Exception/` — Domain-specific exceptions
